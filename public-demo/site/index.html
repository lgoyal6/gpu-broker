Native source, recording and limits

Recorded results come from gpubroker sim. Browser runs compile and execute the same Go policy.Decide and simulator code. Each browser run accepts one fixed-size synthetic workload, validates the historical carbon dataset checksum and reports evidence_class=simulator. No credentials, GPU job submission, database or cloud worker exists in this demo.
