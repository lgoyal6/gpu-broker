If your job fails because a package is missing

That is the commonest reason a job dies here. Make a named environment once and everybody who picks it gets the same packages: 

gpu env create vision -r requirements.txt

The first job that uses it builds it; every job after that reuses the build. Your data lives in /data and survives between jobs, so a dataset is downloaded once.

Make it survivable

Jobs can land on spot capacity, which can be taken back with two minutes' notice. If your script checkpoints, it resumes where it stopped; if it does not, it starts over. Add four lines and it will not lose work: 

from gpu_broker.adapters import Checkpointer

ckpt = Checkpointer(model, optimizer, every=500)
start = ckpt.resume()
for step in range(start, total):
    train_one_step()
    if ckpt.step(step): break
